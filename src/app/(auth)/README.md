# (auth)

Login and signup pages. The `(auth)` name only groups them, so URLs are `/sign-in` and `/sign-up`.

- `layout.tsx` - shared frame (navbar + centered card area).
- `sign-in/page.tsx` - login form. Checks input, signs in, goes to `/`.
- `sign-up/page.tsx` - signup form. Checks input, creates account, goes to `/`.
