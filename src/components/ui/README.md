# ui

Basic shadcn/ui building blocks. Copied code that we own, so editing is fine.
Add more with `npx shadcn@latest add <name>`. Delete any you don't use.

- `button.tsx` - buttons (use `nativeButton={false}` when it renders a link).
- `input.tsx`, `textarea.tsx`, `label.tsx` - form inputs.
- `field.tsx` - groups a label, input and error message.
- `select.tsx` - dropdown to pick one option.
- `card.tsx` - boxed section with header and content.
- `dialog.tsx` - popup window.
- `dropdown-menu.tsx` - menu that opens from a button.
- `tabs.tsx` - switch between sections.
- `badge.tsx` - small label/tag.
- `skeleton.tsx` - grey loading placeholder.
- `separator.tsx` - thin dividing line.
- `sonner.tsx` - toast popups (success / error messages).
