# src

All the app code lives here.

- `app/` - the pages (what users see at each URL).
- `components/` - reusable UI pieces (buttons, cards, navbar...).
- `lib/` - setup and helpers (database client, auth config, validation rules).
- `server/` - code that runs only on the server (database reads, actions, session checks).
- `generated/` - made automatically by Prisma. Never edit or read it.
